# بوت إدارة مجموعات تيليجرام (نسخة آمنة)

بوت عربي لإدارة المجموعات بـ Python، بديل آمن لحزمة CHITIR. لا يحتوي أي ملف ثنائي، ولا `sudo`، ولا تنفيذ أوامر نظام، ولا اتصال بأي خدمة خارجية سوى تيليجرام.

## التثبيت
```bash
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
pip install -r requirements-media.txt      # اختياري: يوتيوب + النطق (ويلزم ffmpeg على النظام: apt install ffmpeg)
cp .env.example .env && chmod 600 .env     # ثم عبّئ BOT_TOKEN و DEV_IDS
python3 main.py        # أو ./run.sh للتشغيل مع إعادة التشغيل التلقائي
```

1. أنشئ البوت من `@BotFather` وانسخ التوكن إلى `.env`.
2. من BotFather: `/setprivacy` ← **Disable** (ليرى البوت رسائل المجموعة).
3. أضف البوت للمجموعة كمشرف بصلاحيات: حذف الرسائل، حظر المستخدمين، تثبيت الرسائل.
4. ضع آيدي حسابك الرقمي في `DEV_IDS` (تعرفه من `@userinfobot`).

## الرتب
مميز < ادمن < مدير < منشئ < مالك < مطور (من `DEV_IDS`). مالك المجموعة في تيليجرام = مالك، ومشرفوها = ادمن تلقائيًا.
تستطيع منح أو معاقبة من رتبته **أقل** من رتبتك فقط. المميز معفى من الأقفال.

## الأوامر (تعمل بالعربية بدون شرطة)
| الرتبة | الأوامر |
|---|---|
| الجميع | `ايدي` `رتبتي` `القوانين` `الانذارات` `حاسبه 5*3` `انشاء حساب بنكي` `فلوسي` `بخشيش` `تحويل 100` (بالرد) |
| ادمن | `حظر` `الغاء الحظر` `طرد` `كتم` `الغاء الكتم` `انذار` `مسح الانذارات` `تثبيت` `الغاء التثبيت` `مسح` `رفع مميز` `تنزيل` `المميزين` `الادمنيه` `الحمايه` `الردود` |
| الوسائط (للجميع) | `يوتيوب <رابط أو اسم>` (صوت mp3) · `تحميل فيديو <رابط أو اسم>` · `انطق مرحبا بكم` · `انطق en hello` |
| مدير | `قفل X` / `فتح X` `ضع ترحيب` `تفعيل/تعطيل الترحيب` `ضع القوانين` `اضف رد كلمة = رد` `حذف رد` `مسح الردود` `ضع الانذارات 3` `تفعيل/تعطيل التحميل` `رفع ادمن/مدير` `الغاء تثبيت الكل` |
| مطور | `الاحصائيات` |

أنواع القفل: الروابط، المعرفات، الصور، الفيديو، الملصقات، المتحركه، التوجيه، الملفات، الصوتيات، الجهات، التكرار، الدردشه، البوتات.
الهدف يُحدَّد بالرد على رسالته، أو بآيدي رقمي، أو بـ `@معرّف` (إن سبق أن تكلّم في مجموعة فيها البوت).

## ما الذي يجعله آمنًا
- التوكن من البيئة فقط، ولا يُطبع، ويُحجب من أي سجل (بما فيه سجلات httpx).
- لا `os.execute` ولا `subprocess` ولا `eval`: الحاسبة تحلّل AST بقيود صارمة على الأسس والحجم.
- كل استعلامات SQLite مُعامَلة (لا حقن SQL)، وقاعدة البيانات بصلاحيات 600.
- نصوص المستخدمين (ترحيب/قوانين) تُهرَّب قبل إرسالها كـ HTML، والردود المخصصة تُرسل نصًا عاديًا.
- لا يستطيع أحد معاقبة من رتبته مساوية أو أعلى، ولا منح رتبة مساوية لرتبته (إلا المطور).
- تحديد معدّل للأوامر، وحماية تكرار بكتم 10 دقائق.
- التحويلات البنكية ذرّية داخل معاملة واحدة، ومحدودة المبلغ.
- التبعية الوحيدة `python-telegram-bot` بإصدار مثبّت. شغّل `pip-audit` دوريًا وحدّث الإصدار.
- النشر: `Dockerfile` بمستخدم غير جذري، أو `deploy/safe-bot.service` مع عزل systemd.

## يوتيوب والنطق: كيف تعمل بأمان
- **لا صدفة (shell) إطلاقًا:** yt-dlp يُشغَّل بقائمة وسائط عبر `exec`، فلا يمكن حقن أوامر كما كان في البوت القديم.
- **الروابط:** تُقبل فقط من `youtube.com` و`youtu.be` عبر https، بلا مستخدم ولا منفذ (فلا SSRF نحو شبكتك الداخلية). أي نص آخر يصير بحثًا `ytsearch1:`، والفاصل `--` يمنع تحوّله إلى خيار.
- **البيئة:** العملية الفرعية لا ترث `BOT_TOKEN` ولا أي متغير آخر، وتعمل في مجلد مؤقت 0700 يُحذف دائمًا (نجاحًا أو فشلًا أو إلغاءً).
- **حدود:** 10 دقائق و48MB، بلا بثوث مباشرة ولا قوائم تشغيل، مهلة 150 ثانية تُقتل بعدها العملية، تحميلان متزامنان كحد أقصى، وتحميل واحد لكل مستخدم كل 30 ثانية.
- **تحكم:** للمدير `تعطيل التحميل` في مجموعته، وللمالك `ENABLE_MEDIA=0` في `.env` لتعطيلها كليًا.
- العناوين والنصوص تُرسل كنص عادي أو مُهرَّبة، فلا حقن HTML.

**تنبيهات:**
- yt-dlp يتعطل كلما غيّر يوتيوب شيئًا، فحدّثه دوريًا (`pip install -U yt-dlp`). وقد يحظر يوتيوب عناوين السيرفرات السحابية فتفشل بعض التحميلات.
- النطق عبر gTTS يرسل النص إلى خدمة Google خارجية، فلا تنطق بيانات حساسة.
- تحميل المحتوى المحمي بحقوق نشر قد يخالف شروط يوتيوب أو القانون في بلدك، والمسؤولية على من يشغّل البوت.

## ما لم يُنقل عمدًا من البوت القديم
النسخ القديمة من تحميل يوتيوب والنطق (كانت تمرّر نص المستخدم إلى الصدفة؛ أُعيد بناؤها أعلاه بشكل آمن)، والخدمات الخارجية المجهولة (`api-jack.ml` وغيرها)، ومكتبة `tdlua.so` الثنائية، وأي استخدام لـ `sudo`.
